# X2XHS Studio

把 X 帖子转换成小红书多图内容的 MVP。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：`npm run build`。

## Chrome 插件

1. 打开 `chrome://extensions`，开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择 `extension` 文件夹。
3. 打开小红书内容创建页面并保持登录。
4. 在 Studio 点击“发送到插件”，再点击插件里的“填入当前内容”。

当前插件会把标题和正文填入页面中可识别的文本编辑器；小红书的 DOM 和上传接口会随版本变化，图片上传需要针对当前页面结构继续适配。

## 内容解析接口

目前默认使用浏览器端演示生成器，方便无 API key 直接体验。生产接入时，将 `splitIntoCards` 替换为后端接口即可；X 页面若不可访问，也可以直接粘贴正文。
